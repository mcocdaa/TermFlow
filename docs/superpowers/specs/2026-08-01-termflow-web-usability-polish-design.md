# TermFlow Web 可用性修整设计

## 目标

本轮只修整现有 B 内置 Web C 和 B 的注册码时效，不改变 A 权威 tmux 尺寸、
Term/Window/Pane 模型或 A-B-C 边界。重点是让注册、电脑管理、控制中心和终端页的
交互语义与真实后端行为一致。

## 注册码生命周期

- B 生成高熵注册码，只持久化哈希、创建时间、到期时间和使用时间。
- 默认有效期统一为 60 秒；HTTP API 与 `termflow-control enrollment create` 使用同一
  配置值，避免两条签发路径漂移。
- 注册消费继续使用数据库条件更新，保证并发请求最多一个成功。
- 关闭弹窗或页面不会撤销已复制的注册码。它在首次成功消费或 B 记录的 60 秒到期点
  失效；安全边界只依赖 B，不依赖浏览器是否发出关闭事件。
- 用户生成注册码后若保持弹窗打开，到期时 Web C 自动向 B 申请新码并同时替换注册码、
  登录命令与倒计时。关闭弹窗时停止刷新，且不在浏览器存储注册码。
- 弹窗删除“一次 termflow login 代表一台 Computer”的冗余说明。注册码和终端执行命令
  各有标题；命令标题旁使用可聚焦的帮助图标，悬浮或键盘聚焦时说明应将命令复制到已
  安装 TermFlow 的电脑终端执行；主按钮文案为“复制命令”。

## Computer 元数据与时间

- `hostname` 是 A 在登录时报告的操作系统主机名。旧记录或未携带元数据的 API 客户端
  可能为空，这不是另一种 Computer 类型。界面为空时隐藏该行，不展示“未报告
  hostname”或孤立的分隔符。
- 现有 `platform` 实际来自 A 的操作系统标识，因此表头改为“操作系统”。TermFlow
  客户端版本单独标注，不暗示该列是插件或未来平台类型。
- Computer 名称本身是编辑入口。移除名称后的独立“编辑”按钮；点击名称进入原有的
  内联编辑，保留 Enter 保存、Escape 取消、保存失败回滚和可见焦点反馈。
- 注册时间取 B 创建 Installation 记录的 UTC 时间；最近在线时间取 B 收到 A 注册、
  心跳或拓扑更新时写入的 UTC 时间。A 的本地时钟不参与这两个值。
- API 继续传输带时区的 ISO 8601 UTC 时间；Web C 使用浏览器当前时区格式化，并显示
  时区缩写。页面注明“由 B 记录，按当前设备时区显示”，不把 B 主机所在时区当作用户
  时区。

## 控制中心 Term 交互

- 在线 Term 的整行变成一个可访问的路由链接，主标题直接显示真实 Term 名称；删除
  “打开终端”按钮。悬浮、键盘聚焦和按下状态使用统一主题色增强背景、边框与位移反馈。
- 离线 Term 保持不可跳转，并用状态样式表达不可操作，不伪装成可点击链接。
- Computer 卡片的 hostname/操作系统元数据先过滤空值再连接，杜绝只显示一个“·”。

## 终端页布局与菜单

- 终端页使用两行 Grid：真实高度的标题栏与 `minmax(0, 1fr)` 终端区域。终端路由下的
  app shell、main 和页面容器固定为 `100dvh` 且 `overflow: hidden`，不再用
  `calc(100% - 3.25rem)` 猜测标题栏高度。
- 终端标题区紧跟返回按钮左对齐；操作区以 `margin-inline-start: auto` 靠右。
- “适应窗口”按远端 A 报告的 rows/cols 和实测 cell 尺寸等比缩放完整 tmux 网格。
  该模式重置客户端额外平移/缩放，终端外框与 xterm viewport 不显示滚动条。
- 50%、75% 和 100% 仍保持 A 尺寸权威，并只允许在终端区域内部滚动或触控平移；页面
  本身始终不滚动。Terminal host 不再用未计入网格尺寸的内边距压缩 xterm 渲染区域。
- “显示”“Tmux 操作”“聚焦 Pane”仅点击展开。按钮用 `aria-expanded`、主题高亮与旋转
  Chevron 明确反馈展开状态；移除 Tmux 菜单的 hover 预览状态。

## 图标与许可

Web C 使用 `lucide-vue-next` 的树摇 SVG 组件替换返回箭头、展开三角、单选圆点、帮助、
关闭等字符图标。Lucide 主项目采用 ISC 许可证，源自 Feather 的部分图标保留 MIT
许可；依赖锁文件固定实际版本。图标不单独编码业务语义，所有图标按钮保留可访问名称。

## 验证

- Python 测试覆盖默认 60 秒配置、HTTP/CLI 签发时效及单次消费。
- Vitest 覆盖自动换码、弹窗文案/帮助、点击名称编辑、空元数据、整行 Term 链接、菜单
  点击展开与图标状态。
- Playwright 在一次性容器、数据库和端口中运行，断言适应窗口时页面与终端框均无溢出、
  菜单不会因 hover 展开、整行 Term 可跳转，并保存桌面/移动端视口截图。
- 完整 lint、类型检查、构建和测试通过后才重建 B 镜像；部署复用现有 B 数据卷，验证 A
  重新连入且原有 tmux 会话未被修改。
