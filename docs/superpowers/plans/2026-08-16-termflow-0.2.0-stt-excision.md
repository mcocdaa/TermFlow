# TermFlow 0.2.0 STT Excision Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the provisional M7/STT implementation so C submits only ordinary text and A/B/protocol/deployment remain completely unaware of how C produced it.

**Architecture:** Fully excise the server transcription API/provider/state, STT-specific contracts, the current C audio-upload path, and deployment/release surfaces. Preserve the existing Agent text composer and message submission path unchanged. Because 0.2.0 is unreleased, rewrite migration 0006 to materialize the corrected final schema directly.

**Tech Stack:** Python 3.12, FastAPI, Pydantic, SQLAlchemy/Alembic, TypeScript, Vue 3, Tauri/Rust, Docker Compose, pytest, Vitest, Cargo.

**Approved design:** `docs/superpowers/specs/2026-08-16-m7-stt-scope-correction-design.md`

**Execution constraint:** Run inline with `superpowers:executing-plans`; do not dispatch subagents. The worktree already contains mixed, uncommitted OpenCode/container fixes. Preserve and commit those non-STT changes before editing shared files.
