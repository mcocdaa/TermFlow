## Scope decisions (user, 2026-08-22)

1. **M3 shell-marker capability is removed from 0.2.0.** Shell integration
   would require installing markers into Computer A's rc files; the user ruled
   that A must not be modified ("不能改A端"). The three baseline watch
   conditions (`output_contains`, `output_idle`, `pane_exited`) remain the
   shipped surface. Recorded in the master plan alongside the M7 precedent.
2. **Production runtime gating is simplified.** The elaborate supervisor
   attestation ceremony is reduced to an HTTP health probe: a runtime is
   admitted when its OpenCode endpoint answers `/global/health` with valid
   basic auth. Remaining protections stay in force: hashed agent-token auth on
   the MCP endpoint, exact tool allowlist, shared-endpoint isolation guard,
   one-active-run serialization, and epoch invalidation on revoke/profile
   change. Plain B restarts must NOT rotate epochs (rendered credentials
   survive restarts).
